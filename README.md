# Hola, soy Carlos 👋

Desarrollador **frontend** de Puigmoreno (Teruel), afincado en Zaragoza desde hace 10 años, al que le encanta hacer de todo: interfaces cuidadas, backends pequeños, juegos en 3D, apps móviles, temas de WordPress y herramientas para automatizar lo que me aburre.

## En qué trabajo

- 🎨 **Frontend:** React, Next.js, Vue/Nuxt, Astro, TypeScript y Tailwind CSS.
- 🧱 **Backend y datos:** Node.js, Hono, PHP, PostgreSQL (Neon), SQLite/Turso y Drizzle.
- 📱 **Móvil y PWAs:** Flutter, Expo y aplicaciones instalables con modo offline.
- 🎮 **Three.js y creatividad:** escenas 3D procedurales, mapas y visualización de datos.
- 🧩 **WordPress:** plugins y temas a medida (Elementor, WooCommerce, Flatsome).
- ☁️ **Despliegue:** Vercel, Docker y GitHub Actions.
